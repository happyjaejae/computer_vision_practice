# 1차 업무: Git 활용 및 픽셀 단위 이미지 처리 실습

## 📝 프로젝트 개요
이 프로젝트는 **Computer Vision** 프로젝트의 기초 역량을 다지기 위해 수행되었습니다. Git을 활용한 효율적인 코드 버전 관리 방법을 익히고, OpenCV를 사용하여 픽셀 단위의 이미지 처리 및 데이터 전처리(Preprocessing) 파이프라인을 구축하는 것을 목표로 합니다.

## 🚀 주요 기능
1. **특정 색상 검출 (Basic)**
   - HSV 색상 공간을 활용하여 빨간색(Red) 영역을 감지하고 마스킹 처리합니다.
   - 대상 파일: `red_filter.py`

2. **이미지 데이터 전처리 및 증강 (Advanced)**
   - **크기 조정 (Resize)**: 224x224 픽셀로 정규화
   - **이상치 탐지**: 평균 밝기를 기준으로 너무 어두운 이미지 필터링
   - **노이즈 제거**: Gaussian Blur 적용
   - **데이터 증강**: 좌우 반전(Flip)을 통한 데이터셋 확충
   - 대상 파일: `image_preprocessing.py`
